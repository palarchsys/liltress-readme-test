Diese Seiten teilen die Anleitung des Arbeitsplatzes in ein Thema pro Datei.

Das bereits angelegte Ubuntu-Konto wird nicht ersetzt.

Der Installer legt kein zweites Konto an.

Der installierte Baum ist `/opt/liltress-workstation`.

`secrets.conf` bleibt auf der Maschine. Kopieren Sie die Datei nicht in eine Nachricht, ein Ticket oder ein Repository.

Öffnen Sie ein Thema über die Navigation oben. Dasselbe Menü steht auf jeder Seite.
