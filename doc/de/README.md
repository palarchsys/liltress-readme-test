# 🛡️ Liltress Workstation 🛡️

![Ubuntu 26.04 or newer](https://img.shields.io/badge/Ubuntu-26.04%2B-E95420?logo=ubuntu&logoColor=white)
![Workstation](https://img.shields.io/badge/profile-workstation-1f6feb)
![Unbound](https://img.shields.io/badge/DNS-Unbound-0055A4)
![UFW](https://img.shields.io/badge/firewall-UFW-0055A4)
![Security checks](https://img.shields.io/badge/checks-AIDE%20%C2%B7%20ClamAV%20%C2%B7%20Lynis-2ea44f)

Liltress Workstation bereitet einen Arbeitsplatz mit Ubuntu 26.04 oder neuer vor.<br/>
Es installiert den lokalen DNS-Resolver, die Firewall und die Sicherheitsprüfungen.

Das bereits angelegte Ubuntu-Konto wird nicht ersetzt.<br/>
Der Installer legt kein zweites Konto an.

Der installierte Baum ist `/opt/liltress-workstation`.<br/>
`secrets.conf` bleibt auf der Maschine. Kopieren Sie die Datei nicht in eine Nachricht, ein Ticket oder ein Repository.

Öffnen Sie ein Thema über die Navigation unten. Dasselbe Menü steht auf jeder Seite.
