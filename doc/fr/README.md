Ce jeu de pages découpe le guide du poste en un sujet par fichier.<br/>
Le compte Ubuntu déjà créé sur la machine n'est pas remplacé.<br/>
L'installeur ne crée pas un second compte.<br/>
L'arbre installé est `/opt/liltress-workstation`.<br/>
`secrets.conf` reste sur la machine. Ne le copiez pas dans un message, un ticket ou un dépôt.<br/>
Ouvrez un sujet depuis la navigation ci-dessous. Le même menu est répété sur chaque page.
