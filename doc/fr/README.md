Ce jeu de pages découpe le guide du poste en un sujet par fichier.

Le compte Ubuntu déjà créé sur la machine n'est pas remplacé.

L'installeur ne crée pas un second compte.

L'arbre installé est `/opt/liltress-workstation`.

`secrets.conf` reste sur la machine. Ne le copiez pas dans un message, un ticket ou un dépôt.

Ouvrez un sujet depuis la navigation ci-dessus. Le même menu est répété sur chaque page.
